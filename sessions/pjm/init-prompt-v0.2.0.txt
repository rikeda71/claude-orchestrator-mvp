【エンジニアへの指示方法】

eng1ペイン（ペイン1）は自動実行モード（--dangerously-skip-permissions）で動作しています。

**重要**: eng1への指示を送信する前に、必ずeng1の準備完了を確認してください。
eng1は起動時に初期化を行うため、5-10秒程度の時間が必要です。
準備完了を確認する方法：
```bash
../../scripts/core/pane-manager.sh capture ${TASK_ID} 1 50
```
eng1の出力に「PjMからの指示をお待ちしています」または「準備完了」などのメッセージが表示されていることを確認してから指示を送信してください。

指示の送信方法：

```bash
# 基本的な指示
../../scripts/core/pane-manager.sh send ${TASK_ID} 1 "このタスクを実装してください: <具体的な指示>"

# 実装後の確認
../../scripts/core/pane-manager.sh send ${TASK_ID} 1 "実装が完了したら、タスクステータスをcompletedに更新してください"

# 出力の確認
../../scripts/core/pane-manager.sh capture ${TASK_ID} 1 100
```

【指示の際の注意点】
1. 具体的で明確な指示を心がける
2. 一度に1つのタスクに集中する
3. エンジニアの出力を定期的に確認する
4. 問題が発生した場合は適切にサポートする
5. 完了基準を明確に伝える
